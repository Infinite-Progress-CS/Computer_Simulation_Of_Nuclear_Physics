# 五维势能面 + 随机行走 + 分屏 3D 动画（FRLDM 有限力程液滴模型）

基于随机行走的重核合成最优路径预测——原子核裂变仿真的核心脚本。
在五维形变参数空间上构建核裂变势能面（PES），用 Metropolis 随机行走探索势能面，
并给出确定性极小能量（绝热）裂变路径与分屏动画。

## 一、物理模型

### 1. 3QS（三段二次曲面）形变参数化
核形状由三段光滑拼接（C¹ 连续）的二次曲面组成：左椭球 + 中间二次曲面 + 右椭球。

五个形变参数：

| 参数 | 符号 | 物理含义 | 取值范围 |
|------|------|----------|----------|
| q1   | elong | 拉长（碎片质心间距） | 0.3 ~ 3.0 |
| q2   | neck  | 颈部粗细（颈半径/碎片半径） | 0.05 ~ 0.99 |
| q3   | eta   | 质量不对称 η=(M_H−M_L)/(M_H+M_L) | −0.5 ~ 0.5 |
| q4   | eps1  | 左碎片形变 ε_f1（Nilsson 四极） | −0.2 ~ 0.4 |
| q5   | eps2  | 右碎片形变 ε_f2 | −0.2 ~ 0.4 |

### 2. FRLDM 宏观能量（无壳修正）
采用 Möller 2004 框架的有限力程液滴模型（FRLDM）：

- **表面能**：Krappe–Nix–Sierk（KNS）Yukawa-plus-exponential 面积分
  `I_surf = ∮∮ [2−(2+s/a)e^{−s/a}] (s·da1)(s·da2)/s⁴`
- **库仑能**：电荷密度双层积分
- 无壳修正、无配对修正（纯液滴）。

目标核素 **U-236**（Z=92, N=144）：R0=7.169 fm，E_S0=716.9 MeV，E_C0=1020.1 MeV，
裂变参数 x = E_C0/(2E_S0) = 0.711。

## 二、算法

- **Metropolis 随机行走**：`p(q→q') = min(1, e^{−ΔV/T})`。
  两段式退火——越障前恒温 T 保证越过势垒，一旦 elong 越过棘轮阈值（2.3）才冷却到 T_end，
  模拟裂变断裂的不可逆性。
- **极小能量（绝热）路径**：在每个 elong 下对 neck 取极小（eta=eps=0，对称裂变），
  即随机行走要逼近的"最优路径"。

## 三、结果

- **裂变势垒高度**：12.66 MeV @ elong=2.15（粗颈鞍点）
- **断裂点**：−14.31 MeV @ elong=3.00, neck=0.05（两碎片）
- **路径**：球(0.3) → 拉长(neck=0.99) → 势垒(2.15) → 颈缩过渡 → 断裂(3.0, 两碎片)

## 四、已知局限（重要）

0. **数值收敛性（本次复核发现）**：库仑积分用 Legendre 高斯求积，在尖表面（尤其细颈
   neck≈0.05）处被积函数有端点奇异性，收敛 ~1/n 很慢。默认 nz=nrho=30 网格下库仑能
   **未收敛**（断裂点误差 ~10 MeV，曾误报势垒 17.09 / 断裂点 −3.83）。现采用分层网格：
   随机行走 nz=nrho=30（粗，只需相对能量）、势垒/断裂点 nz=nrho=60（细）、势能面切片
   nz=nrho=40（中）。n=60 相对 n=100 的收敛误差：势垒 ~0.9 MeV、断裂点 ~1.9 MeV。

1. **势垒偏高**：12.7 MeV，约为实验值 ~5.9 MeV 的 2 倍。原因：
   (a) 纯液滴模型（FRLDM 无壳修正）本身势垒偏高（~2–9 MeV）；
   (b) 3QS 形状空间受限（只有三段二次曲面，无法表示任意形状）。
2. **颈部过渡势垒（假象）**：3QS 中"细颈"与"碎片分离"被解耦，固定 elong 下把颈
   从粗变细会先升能再降能，产生一个 ~25 MeV 的颈部过渡势垒（物理上颈变细与碎片
   分离是同一个耦合过程）。这是参数化的局限，靠棘轮（elong 单调不减）绕过。
3. **Metropolis 行走的随机性**：单条行走（尤其不同随机种子）不一定在有限步数内
   越过势垒到达断裂点；这是热激活的本质。确定性极小能量路径提供了干净的裂变轨迹。
