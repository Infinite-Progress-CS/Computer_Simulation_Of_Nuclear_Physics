# 核物理计算机仿真（Computer Simulation of Nuclear Physics）

重核裂变 / 合成的最优路径预测：在**五维核形变势能面**上做 **Metropolis 随机行走**采样，
找极小能量（绝热）裂变路径。目标核素 **U-236**（Z=92, N=144）。

## 子项目

| 目录 | 说明 |
|------|------|
| [`五维势能面上原子核的随机行走/`](五维势能面上原子核的随机行走/) | **当前主线**：宏观-微观模型（FRLDM 液滴 + Strutinsky 壳修正 + BCS 对修正）模块化实现，含完整公式/模型/结果文档 |
| [`原子核裂变仿真代码/`](原子核裂变仿真代码/) | 早期纯液滴 FRLDM 单文件版本（无壳修正），势垒 12.66 MeV，作为对比基线 |

## 说明

- 两个文件夹是同一问题的两代实现：**纯液滴**（旧）与**宏观-微观**（新），详见各自 README。
- 纯液滴模型势垒 12.66 MeV ≈ 物理值 5.9 MeV 的 2 倍，且只能预言对称裂变；
  加壳修正 + 对修正后，势垒压回 ~5.9 MeV 双峰，并复现非对称裂变（η≈0.19，碎片 ~140/~96）。
- 全部数学物理公式、参数取值与代码位置对照见
  [`五维势能面上原子核的随机行走/docs/公式说明.md`](五维势能面上原子核的随机行走/docs/公式说明.md)。
