# 模型说明

## 1. 总体框架：宏观-微观模型

重核（U-236, Z=92, N=144）的形变势能写为三项之和：

```
E(q) = E_液滴(q) + δE_壳(q) + δE_对(q)
```

- `E_液滴`：FRLDM 有限力程液滴模型形变能（表面项 + 库仑项）
- `δE_壳`：Strutinsky 壳修正（单粒子能级来自变形 Woods-Saxon 势）
- `δE_对`：BCS 对修正

三者同源解决纯液滴模型的三个已知缺陷：

1. **均等分裂**：纯液滴预言对称裂变（η=0），但真实 U-236 是非对称裂变（碎片 ~140/~96）——加壳修正后，
   双幻数附近（N=82、Z=50）的非对称碎片更稳，η≈0.19 能量更低。
2. **势垒偏高**：纯液滴势垒 12.66 MeV ≈ 物理值 5.9 MeV 的 2 倍——壳修正把鞍点压回 ~5.9 MeV 双峰。
3. **轨迹直线**：3QS 拉长-颈缩解耦导致直角折线——量子修正后路径更平滑。

## 2. 形状参数化：3QS 三二次曲面

`Shape3QS` 用 5 个无量纲参数描述轴对称形状：

| 参数 | 含义 | 裂变演化范围 |
|------|------|-------------|
| `elong` | 两碎片质心间距（拉长） | 0.4（球）→ 2.5~3.0（分离） |
| `neck` | 颈部粗细 ∈(0,1]，`neck=1` 球形、`neck→0` 断裂 | 0.99 → 0.15（物理断裂颈） |
| `eta` | 质量不对称 = (M_H−M_L)/(M_H+M_L) | 0 → 0.19 |
| `eps1` | 左/轻碎片形变 | 0 → 0.40（轻碎片形变大） |
| `eps2` | 右/重碎片形变 | 0 → 0.10（重碎片近 N=82 幻数，近球形） |

颈部半径 `rho_v = neck × min(a1, a2)`，乘以核半径 R0≈7.17 fm 后为物理颈半径。
`neck=0.15` 对应颈半径 ~0.7 fm，接近真实断裂（scission）尺度；`neck→0.001` 则颈半径
~0.005 fm，已是不物理的针尖（只用于动画最后一帧表示"断口"）。

## 3. 单粒子势：变形 Woods-Saxon

`WoodsSaxon` 用轴对称变形谐振子基对角化求单粒子能级：

```
V(r) = V0·[1 ± κ·(N−Z)/A] / (1 + exp(d(r)/a)) + V_so(r) + V_Coul(r)
```

- `d(r)` 为到 3QS 表面的带符号距离（核内负、外正）
- 自旋轨道项按 `l_z·s_z` + 升降项在谐振子基做数值积分
- 基截断 `N_max = 12`（A=236 够用），按 (Ω, π) 分块对角化

**参数（universal Woods-Saxon）**：`V0=49.6 MeV`、`κ=0.86`、`r0=1.275 fm`、`a=0.70 fm`、
`λ_so=35`、`r0_coul=1.16 fm`；谐振子 `ħω0 = 41/A^(1/3) ≈ 6.63 MeV`。
每个单粒子能级因时间反演（Kramers）2 重简并。

## 4. 壳修正与对修正

- **Strutinsky 壳修正**（`strutinsky.py`）：高斯 × Laguerre 曲率修正（阶 p=6）平滑能级密度，
  宽度 `γ = 0.9 ℏω0 ≈ 6.0 MeV`。`δE_壳 = Σ_占据 ε_i − ∫^{λ̃} ε g̃(ε) dε`。
- **BCS 对修正**（`pairing.py`）：费米面 ±6 MeV 窗口内解能隙方程，配对强度 `G = 16/A MeV`，
  `δE_对 = −Δ²/G` 量级 ~ −1.5 MeV。

## 5. 分步流程

**二维对称路径验证**（`scripts/symmetric_path_validation.py`）
1. 球 U-236 单粒子能级在幻数处有壳能隙（N=82、N=126、Z=50、Z=82）。
2. 球壳修正 δE_壳 符号正确：U-236 为 mid-shell，球形壳修正为正 ~+20 MeV（驱动形变）。
3. 对称路径势垒从纯液滴 12.66 MeV 降到 ~5.9 MeV 且出现双峰（内/外鞍点）。
4. 固定 elong 扫 η：非对称（η≈0.19）能量低于对称（η=0）。

**ε 形变弛豫与双峰势垒**（`scripts/epsilon_relaxation.py`）
对称裂变下对每个 elong 在 (ε, neck) 空间取极小，得到含 ε 弛豫的"真实裂变路径"：
定位基态（ε≈0.24 长椭球）、从真基态测量双峰势垒。

**随机行走 + 动画**（`scripts/run_walk.py`、`scripts/run_walk_asym.py`）
把 `MacroMicro` 接入 Metropolis 随机行走，在 5D 势能面上采样，并生成
"球 → 拉长 → 颈缩 → 非对称 → 分离成两个碎片"的 3D 分屏动画。
