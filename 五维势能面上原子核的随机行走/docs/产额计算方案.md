# 裂变碎片产额计算方案

> 目标：在宏观-微观模型（FRLDM + Strutinsky + BCS）+ 5D 势能面 + Metropolis 随机行走的**基础上**，
> 计算 U-236 裂变碎片的产额分布 Y(A)，并与 ENDF 实验数据对照。
> 原有代码（液滴 / 壳 / 对 / 单粒子 / Metropolis）**全部复用，不重写**。

## 二、新增模型

| 模型 | 性质 | 说明 |
|------|------|------|
| 断裂点模型（scission-point） | 🔴 核心 | `Y ∝ exp(−V/T)`，碎片分布由断裂瞬间势能决定 |
| 费米气体核温度 | 🟡 辅助 | `T = √(E*/a)` |
| 碎片壳修正（复用 Strutinsky） | 🟡 辅助 | 对象从「母核 U-236」换成「碎片核 (A,Z)」 |
| 布朗形变系综 | 🟢 进阶 | 随机行走升级成统计系综（路线 B） |

## 三、新增公式

```
① 碎片间库仑能（经典电学）
   E_Coul = e² Z_L Z_H / d

② 断裂点产额（核心）
   Y(A_L, Z_L) ∝ exp[ −V_scission(A_L, Z_L) / T ]
   V_scission = [E_LD + δE_shell + δE_pair]_L + [同]_H + E_Coul

③ 核温度（费米气体）
   T = √(E*/a),   a ≈ A/8 MeV⁻¹

④ 质量/电荷不对称（代数）
   A_L = (1−η)A/2,  A_H = (1+η)A/2,  Z_L = (Z/A)·A_L  (UCD)

⑤ 能级密度前置因子（可选）
   ρ(E*) ∝ exp(2√(a E*))
```

## 五、编程方案（7 步）

| 步 | 做什么 | 验证标准 |
|----|--------|---------|
| 0 | 抓 ENDF 数据：U-235(n_th,f) 累计质量链产额 | 得到 `data/*.csv`，双峰可见 |
| 1 | 写 `fragment.py`：复用 woods_saxon/strutinsky/pairing 算任意碎片核 (A,Z) 形变下能量，对 β 取极小 | N=82 附近碎片算出大且负的壳修正 |
| 2 | 写 `level_density.py`：`T=√(E*/a)` | T ≈ 0.75~1 MeV |
| 3 | 写 `scission.py`：组两碎片 + 库仑 → `V_scission` → `Y ∝ exp(−V/T)` | 单一 (A_L,Z_L) 能算出产额 |
| 4 | 写 `yield_model.py`：遍历 A_L=70~166、Z_L，归一化 Y(A)、Y(Z) | Y(A) 出双峰 |
| 5 | 写 `calc_fragment_yield.py`：串起全流程 + 出图 | 一跑出理论 Y(A) |
| 6 | 写 `compare_yield_experiment.py`：和 ENDF 叠图，调 T | 峰位 ~95/~139、谷深 ~1/600 大致重现 |
| 7 | （进阶）`brownian_yield.py`：Metropolis 系综 + 断裂点记录 η → 直方图 | 与路线 A、实验三方一致 |
