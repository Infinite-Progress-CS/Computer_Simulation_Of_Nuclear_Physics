# U-236 裂变碎片产额分布：计算结果（含 β₂ 形变）

## 结论（一句话）

用**断裂点模型**（FRLDM 液滴 + Strutinsky 壳修正 + BCS 对修正 + β₂ 椭球形变，
电荷弥散）复现 U-236 热中子裂变的**非对称双峰**质量产额 Y(A)：对称谷 A=117 精确
对准实验 A=118，峰谷比可调；β₂ 形变把所需有效温度从 2.0 降到 **1.6 MeV**（朝物理
1.0~1.3 MeV 收敛）。峰位仍在 A=103/133，比实验初级峰 A=100/136 各偏 3 个质量单位
（偏对称），根因是双幻数 Sn-132 被过强绑定。

## 关键结果（β₂ 形变基态模型，T = 1.6 MeV）

| 量 | 计算 | 实验(对称化初级) | 实验(原始,发射中子后) |
|---|---|---|---|
| 轻峰 A | 103 | 100 | 95 |
| 重峰 A | 133 | 136 | 134 |
| 对称谷 A | 117 | 118 | 118 |
| 峰谷比 | 788 | 556 | 634 |
| RMS log₁₀ 偏差 (A 80~155) | 1.045 | — | — |

温度扫描（同一套碎片能量，仅换 T）：

| T (MeV) | 轻峰 A | 重峰 A | 峰谷比 |
|---|---|---|---|
| 1.0 | 104 | 132 | 6.4×10⁴ |
| 1.2 | 104 | 132 | 8.9×10³ |
| 1.4 | 103 | 133 | 2.2×10³ |
| **1.6** | **103** | **133** | **788** |
| 1.8 | 103 | 133 | 354 |
| 2.0 | 103 | 133 | 187 |

> 球形模型需 T=2.0 才能达到实验峰谷比 634；加 β₂ 形变后 T=1.6 即达 ~600，
> 形变能确实把壳修正压弱、降低了所需温度。

## 对照口径（重要）

ENDF 质量链产额是**发射中子后**的累计产额，重碎片多蒸 ~0.5 个中子 → 分布不对称
（轻峰 A=95、重峰 A=134）。计算模型给出**发射前（初级）**产额（A_L+A_H=236 严格
守恒），二者不可直接比。对称化：

```
Y_primary(A) = [Y(A) + Y(236 − A)] / 2
```

折叠后初级峰在 A=100 / 136，谷仍在 A=118。**本文所有对比都以对称化实验为准**。

## 模型

```
Y(A_L, Z_L) ∝ exp(−V_scission(A_L, Z_L) / T)
Y(A_L)      = Σ_{Z_L} Y(A_L, Z_L)                 （电荷弥散，UCD ± 4）
V_scission  = E_frag(L) + E_frag(H) + e² Z_L Z_H / d
E_frag(ε)   = E_S0·B_s(ε) + E_C0·B_c(ε) + a_sym I²A + δE_壳(ε) + δE_对(ε)
碎片基态    = min_{ε∈[0,0.4]} E_frag(ε)           （β₂ 椭球，幻数核球、中壳核形变）
```

- **壳修正**：Strutinsky 能级求和法（解析 CDF），p=4，γ = 1.1 ħω₀；变形 Woods-Saxon
  椭球势，Nmax=12。验证：Sn-132 双幻数 −12.36 MeV（ε=0）、Zr-100 形变极小 ε=0.3。
- **形变**：`ShapeSpheroid` 椭球，B_s/B_c 精确公式（长椭球 arcsin/ln 式）。
- **断裂距离**：d = 1.16(A_L^{1/3} + A_H^{1/3}) + 2.0 fm。

## 双峰物理来源

断裂点势能随不对称度（轻碎片质量 A）竞争：

1. **液滴 + 库仑**：对称裂变（A=118）能量最低 → 预言对称。
2. **壳修正**：对称碎片中壳惩罚（Pd-118 +22 MeV），重碎片到 N=82 壳修正大幅降低
   → 非对称裂变，重峰由 **N=82** 驱动。

## 已做的改进与验证

1. **β₂ 椭球形变**（`fragment.py` ground_state 对 ε 求最小）：幻数核（Sn-132）保持
   球形（ε=0），中壳核（Zr-100）落到形变极小（ε=0.3）。→ 温度 2.0 → 1.6 MeV。
2. **断裂点形变诊断**（`scripts/test_scission_deformation.py`）：
   - **二维最小化** (ε_L, ε_H) 无用：Sn-132 自己选 ε=0 保持球形、锁死双幻数，结果
     等同基态。
   - **固定断裂形变**（非绝热，碎片在断裂瞬间被库仑拉伸到统一 ε_sc）：
     - ε_sc=0.10：T≈1.3 MeV 即达实验峰谷比，峰形加宽（更接近实验 6.3% 峰高）。
     - ε_sc=0.15：壳进一步洗掉，峰谷比崩塌到 ~6（过度）。
     - 结论：断裂形变 ε_sc≈0.10 是物理机制（改善温度与峰宽），但**不移动峰位**。

## 已知局限（对应论文讨论点）

1. **峰位偏 3 个质量单位（偏对称）**：轻峰 A=103 vs 100、重峰 A=133 vs 136。
   - 重峰被 **Sn-132 双幻数**（Z=50 + N=82）过强绑定；实验重峰在 **Xe-136/Ba-138**
     （仅 N=82，Z=54~56）。即质子 Z=50 幻数在断裂点应被洗掉、N=82 存活，但本模型
     中两者随形变同等溶解。
   - 轻峰由 N=62 形变壳闭合（Mo-104）拖住，实验在 Z=40/N=60（Zr-100）。
   - 本质是 Woods-Saxon 单粒子谱给出的幻数/壳闭合位置与实验有 ~2~4 个核子偏移，
     属模型参数（κ、r0、自旋轨道强度）层面的系统偏差。

   **调参排查（已证伪，记录于此处）**：针对"调 WS 参数修幻数位置"的选项做了系统排查：
   - **修复奇偶交错 bug**：`strutinsky.py` 原用 `round(n_particles/degeneracy)` 取占据
     轨道数，银行家舍入使奇数核（Z=51 多算 1 个核子、Z=53 少算 1 个）壳修正出现
     锯齿交错（Sb-133 假 −18.8 MeV）。改为 `n_full//n_extra` 部分占据后平滑单调
     （Sn−12.4→Sb−10.2→Te−8.2→…→La−1.5）。这是真实 bug，已修复。
   - **λ_so_p↓（质子自旋轨道强度 35→15）**：溶解 Z=50，Sn-132 ε=0 从 −12.4→−6.9，
     但 Sn 仍比 Xe（−4.6）深；Xe 反超 Sn 的交叉点发生在 ε≈0.1，而重碎片基态锁 ε=0
     球形，交叉点用不上。
   - **λ_so_n↑（中子自旋轨道 35→55）**：对本模型 N=82 能隙几乎无影响（N=82 能隙
     对中子 SO 强度不敏感）。
   - **全量快速对比实证**（降采样 Nmax=10）：λ_so=(35,35)→峰 A=104/132 峰高 43.9%；
     λ_so=(55,15)→峰 A=104/132 峰高 **15.6%**。峰位纹丝不动，仅峰高崩 2.8 倍（双峰
     被洗平）。
   - **γ（Strutinsky 平滑宽度）结构矛盾**：γ=1.1ħω₀ 是重碎片 N=82 的合理选择（Sn
     −12.4），但把轻碎片 N=60/Z=40 形变闭合洗掉（Zr-100 壳全正）；γ=0.9 时轻碎片
     闭合出现（ε=0.3 处 −2.6）但重碎片壳翻正（+3）破坏双峰。单一 γ 无法同时满足。
   - **结论**：峰位偏 3 是单一 WS 参数集 + 单一 γ 断裂点模型的**结构性局限**，不是
     参数可调的偏差。默认 λ_so=35 是双峰最优，论文据此如实报告局限。
2. **有效温度 1.6 MeV 仍高于物理 1.0~1.3**：壳修正偏强。固定断裂形变 ε_sc≈0.10 可
   降到 ~1.3 MeV，但引入自由参数 ε_sc 且不修峰位，故主结果保留无自由参数的基态模型。
3. 未含中子蒸发（若与原始累计产额比，需卷积 ν(A) 锯齿形中子数）、未含 β₄ 十六极形变。
