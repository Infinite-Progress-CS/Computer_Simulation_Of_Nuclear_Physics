# 非对称裂变复现与排查实验总结

> 目标：在 **5D 形变势能面**（3QS 形状 + 宏观-微观模型）上复现 U-236 热中子裂变的
> **非对称裂变**（重碎片 ~140 / 轻碎片 ~96），并排查最优质量不对称 η 与物理值
> （η ≈ 0.19，A_H ≈ 140）之间的偏差来源。
>
> 结论一句话：非对称裂变**已复现**（最优 η = 0.12，轻碎片形变 / 重碎片近球的形变模式
> 正确），峰位偏 3 个质量单位（A_H=132 vs 物理 136~140）的根因是重碎片在近球形变
> ε₂=0.10 下**保留了球形 Z=50+N=82 双幻数**；该球形幻数在物理断裂形变 ε~0.3 下本应被
> 洗掉，但本模型的变形中子壳 N≈88 又偏弱，两者叠加属结构性局限，非单一参数可调。

---

## 1. 背景

U-236（Z=92, N=144）热中子裂变是典型的**非对称裂变**：初级（发射中子前）碎片为
重碎片 A_H ≈ 140（Xe/Ba 区，N≈82）、轻碎片 A_L ≈ 96（Sr/Zr 区，形变），质量不对称

```
η = (A_H − A_L) / (A_H + A_L) ≈ (140 − 96) / 236 ≈ 0.19
```

纯液滴模型（FRLDM）预言**对称裂变**（η=0，球形基态、无真实双峰）。只有加入量子壳修正
（Strutinsky）+ 对修正（BCS）后，N=82 中子壳才把重碎片推向非对称。本实验在已有
宏观-微观模型基础上，用**双中心壳修正**复现非对称裂变并定位偏差来源。

---

## 2. 模型：双中心壳修正（HybridMacroMicro）

核心问题：满核单中心谐振子基（Nmax=12）在断颈区解不开双中心结构，壳修正的不对称偏好
只有 −1.24 MeV（碎片级应 −10.57 MeV），液滴不对称罚 +2.35 MeV 压过 → 假对称裂变。

修复（`src/hybrid_pes.py` 的 `HybridMacroMicro`）：

| 颈厚 neck | 量子修正 | 说明 |
|-----------|----------|------|
| ≥ 0.5 | 满核单中心 | 势垒区可靠 |
| ≤ 0.15 | 碎片级双中心 | 两碎片各自独立 Woods-Saxon，断颈区正确 |
| 0.15 ~ 0.5 | 线性插值 | 平滑过渡，避免 PES 断裂 |

- **碎片分解**（η>0 → 右侧重碎片）：A_L = round(A(1−η)/2)（轻，形变 ε₁）、
  A_H = A−A_L（重，形变 ε₂）；电荷取 UCD `Z_L = round(Z·A_L/A)`。
- **对修正**在断裂区坍缩为 0（满核 BCS 断颈区 −8 MeV、碎片级奇偶核 −11 MeV 均不可靠）。

---

## 3. 复现结果

5D 极小能量路径（`scripts/run_5d_hybrid.py`，穷举 neck×η×ε₁×ε₂）：

| 点 | elong | neck | η | ε₁(轻) | ε₂(重) | E (MeV) |
|----|-------|------|-----|--------|--------|---------|
| 基态 | 0.90 | 0.99 | 0.00 | 0.00 | 0.00 | −0.05 |
| 势垒 | 2.25 | 0.99 | 0.00 | 0.00 | 0.00 | +6.55（高 +6.59） |
| 断裂 | 2.50 | 0.03 | **+0.12** | **+0.30** | **+0.10** | **−11.85** |

- **非对称裂变复现**：断裂点最优 **η = +0.12**（A_H = 132，Z=51，N=81），非零、非对称。
- **形变模式正确**：轻碎片 ε₁=0.30（形变）、重碎片 ε₂=0.10（近球），与物理
  「轻碎片形变 / 重碎片近球」一致。
- **势垒 +6.59 MeV** 相对物理 ~5.9 MeV 高 12%，仍单峰（无双峰，见「已知局限」）。

> 注：早期记录 η=0.10，因 η 网格 `[0, 0.10, 0.15, 0.19, 0.22, 0.25]` 未含 0.12，漏了真极小；
> 本轮精细扫描（`_diag_scission_eta.py`，Δη=0.02）确认真极小在 **η=0.12**。

---

## 4. 排查：峰位偏 3 的根因精确定位

断裂点（elong=2.5, neck=0.03）扫 η，把总能分解为液滴 + 碎片级壳修正（轻/重 × 中子/质子）：

| η | A_H | Z_H | N_H | E_液滴 | 轻 n | 轻 p | 重 n | 重 p | 总 E |
|---|-----|-----|-----|--------|------|------|------|------|------|
| 0.12 | 132 | 51 | 81 | −1.42 | −0.50 | −0.32 | **−5.62** | **−3.98** | **−11.85** |
| 0.19 | 140 | 55 | 85 | +0.01 | −0.46 | −0.69 | −4.78 | +0.81 | −5.10 |

**根因**：重碎片壳修正（重 n + 重 p）在 η=0.12 为 **−9.60 MeV**，在 η=0.19 仅 **−3.97 MeV**，
差 5.6 MeV，敌不过液滴的 +1.4 MeV 不对称罚。

- 重碎片在近球 **ε₂=0.10** 下**保留了球形双幻数**：Z=51（近 Z=50）质子壳 −3.98、
  N=81（近 N=82）中子壳 −5.62，把峰钉在 A_H≈132。
- 物理上断裂碎片被库仑拉伸到 ε~0.3，球形幻数被洗掉，峰应到 A_H≈136~140。

### 关键证据一：球形幻数随形变洗平（`_diag_heavy_deform.py`）

扫重碎片壳修正随 (N_H, ε)，单位 MeV（UCD 电荷链）：

```
中子壳峰恒在 N=82：  ε=0 → −8.3  →  ε=0.3 → 全部洗平为正
质子 Z=50 壳：       ε=0 → −7.4  →  ε=0.3 → 全正
变形中子壳 N≈88：    ε=0.2 时 N=82 −2.6 / N=88 −2.3  ← 无强形变闭合
```

即**球形幻数只在 ε ≲ 0.15 存活，ε=0.3 完全洗平**；但本 WS 模型没有补上一个足够强的
变形中子壳（N≈88），所以「把重碎片变形」这条路补不回来。

### 关键证据二：质子壳缩放测试（`_diag_proton_shell.py`）

把重碎片质子壳 sh_p 按 f_p 缩放（物理动机：质子壳比中子壳弱、更易被形变洗掉）：

| f_p | 最优 η | A_H |
|-----|--------|-----|
| 1.0（当前） | 0.12 | 132 |
| 0.5 | 0.12 | 132 |
| 0.0（去质子壳） | 0.12 ~ 0.15（132 与 136 打平） | 132/136 |

- 质子 Z=50 壳是峰偏 3 的**主因之一**（去掉它峰挪到 A_H≈136，即物理重峰）；
- 但**到不了 0.19**，说明变形中子壳 N≈88 缺失同样关键 → 非单一参数可调。

---

## 5. 结论与后续选项

**结论**：非对称裂变已复现（η=0.12，形变模式正确），峰位偏 3（A_H=132 vs 物理
136/140）是结构性局限——球形 Z=50+N=82 壳在 ε₂=0.10 过强 + 变形 N≈88 壳缺失。

三条后续（按推荐顺序）：

1. **接受现状**：η=0.12 已是「非对称已复现」，论文如实报告峰位偏 3（`产额计算结果.md`
   的「已知局限」已同口径记录）。断裂点模型 + 产额分布图已交付。
2. **断裂点强制碎片形变**：库仑拉伸 ε~0.3（`scission.py` 的 `scission_energy_2d` 已试，
   但 Sn-132 仍锁 ε=0——库仑增益 ~31 MeV 敌不过壳+表面损失 ~48 MeV）。
3. **升级单粒子基 / 调 WS 参数修 N=88 变形壳**：最治本（Nmax 提升、κ/r₀/自旋轨道
   参数重标定使 N≈88 变形壳出现），但工作量大。
