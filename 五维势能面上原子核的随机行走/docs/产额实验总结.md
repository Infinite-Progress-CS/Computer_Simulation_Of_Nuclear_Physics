# 裂变碎片产额分布实验总结

> 目标核素 **U-236**（Z=92, N=144）热中子裂变。本文总结本次「裂变碎片产额分布」
> 实验在原有「5D 随机行走宏观-微观模型」之上**新增**的模型、公式、文献、代码与交付物。

---

## 1. 新增模型

在已有宏观-微观模型（FRLDM 液滴 + Strutinsky 壳修正 + BCS 对修正 + 变形 Woods-Saxon）
基础上，本次实验新增以下模型/机制：

| # | 模型 | 说明 | 代码 |
|---|------|------|------|
| 1 | **断裂点模型** (scission-point model) | 碎片分布由断裂瞬间势能决定：`Y ∝ exp(−V_scission/T)`（Wilkins-Steinberg-Chasman 1976） | `scission.py` |
| 2 | **电荷弥散** (charge dispersion) | 每个质量 A 在 UCD 附近扫 Z，`Y(A)=Σ_Z exp(−V(A,Z)/T)`，是重现双峰的关键 | `yield_model.py` |
| 3 | **未变电荷密度 UCD** | `Z_L = round(Z/A · A_L)`，固定电荷会让碎片钉在中壳得不到双峰 | `yield_model.py` |
| 4 | **碎片核 β₂ 椭球形变** | 碎片用 `ShapeSpheroid` 椭球，基态对四极形变 ε∈[0,0.4] 求最小（幻数核球、中壳核形变） | `shape.py` / `fragment.py` |
| 5 | **碎片能量模型** | `E_frag = FRLDM系数液滴(解析) + 椭球形变能 B_s/B_c + Strutinsky壳 + BCS对` | `fragment.py` |
| 6 | **断裂点势能** | `V_scission = E_frag(L) + E_frag(H) + e²Z_L Z_H/d` | `scission.py` |
| 7 | **同位旋依赖自旋轨道** | 中子/质子自旋轨道强度可分别调（`λ_so_n` / `λ_so_p`），用于幻数位置调参排查 | `woods_saxon.py` |
| 8 | **中子蒸发/对称化口径** | 发射前(初级)产额与发射后(累计)产额的换算：`Y0(A)=[Y(A)+Y(236−A)]/2` | `compare_yield_experiment.py` |

> 关键区别：父核（5D 随机行走）用**有限力程 FRLDM 面积分**（3QS 形状）；碎片核用
> **FRLDM 系数 + 解析椭球 B_s/B_c**（β₂ 形变），且 Strutinsky 参数取 **p=4、γ=1.1ħω₀**
> （父核为 p=6、γ=0.9ħω₀，因 p=6 高阶波瓣在深幻数处给反号）。

## 2. 新增数学物理公式

以下为本次产额实验**新增**的公式（FRLDM/Strutinsky/BCS/WS/Metropolis 基础公式见
`公式说明.md`）：

### 断裂点产额与势能

```
Y(A_L, Z_L) ∝ exp[ −V_scission(A_L, Z_L) / T ]

V_scission = E_frag(L) + E_frag(H) + E_Coul
E_Coul     = e² · Z_L · Z_H / d
d          = 1.16 · (A_L^{1/3} + A_H^{1/3}) + 2.0   (断裂距离, fm)
```

### 电荷弥散（重现双峰的关键）

```
Y(A_L) = Σ_{Z_L} exp[ −V_scission(A_L, Z_L) / T ]        (UCD ± 4)
Z_L(UCD) = round( Z_parent · A_L / A_parent )
```

### 碎片能量（β₂ 椭球）

```
E_frag(ε) = E_S0·B_s(ε) + E_C0·B_c(ε) + a_sym·I²·A + δE_壳(ε) + δE_对(ε)
E_S0 = a_s·(1 − κ_s·I²)·A^{2/3},  E_C0 = (3/5)·Z²·e²/R0
碎片基态 = min_{ε∈[0,0.4]} E_frag(ε)
B_s(ε)、B_c(ε)：长椭球解析式（arcsin/ln 型）
```

### 核温度

```
T = √(E*/a),  a ≈ A/8 MeV⁻¹
```

### 对称化口径（发射前 vs 发射后）

```
Y_primary(A) = [ Y(A) + Y(A_parent − A) ] / 2
```

### Strutinsky 部分占据修正（本次修复的 bug）

```
n_full  = n_particles // degeneracy      (满占据轨道数)
n_extra = n_particles %  degeneracy      (半满轨道剩余核子数)
E_occ   = degeneracy·Σ levels[:n_full] + n_extra·levels[n_full]
```
> 原 `round(n/degeneracy)` 用银行家舍入，奇数核（Z=51/53）多算/少算一个核子，导致
> 壳修正锯齿交错；改为 `//`/`%` 部分占据后平滑单调。

### 核心结果

| 量 | 计算 | 实验(对称化初级) |
|---|---|---|
| 轻峰 A | 103 | 100 |
| 重峰 A | 133 | 136 |
| 对称谷 A | 117 | 118 |
| 峰谷比 | 788 | 556 |
| 有效温度 T | 1.6 MeV | （物理 1.0~1.3） |

- **双峰复现**：非对称裂变双峰（轻峰 A=103 / 重峰 A=133），对称谷精确对准实验 A=118。
- **β₂ 形变把有效温度从球形 2.0 降到 1.6 MeV**（朝物理值收敛）。
- **峰位偏 3 个质量单位**（偏对称），根因是 Sn-132 双幻数（Z=50+N=82）过强绑定；
  已通过 λ_so/γ 系统性排查确认是**单一 WS 参数集 + 单一 γ 断裂点模型的结构性局限**，
  非参数可调（详见 `产额计算结果.md`「已知局限」一节）。
- **奇偶交错 bug 修复**：Strutinsky 部分占据修正（真实正确性修复）。

## 附：调参排查结论（本次 session 额外产出）

- λ_so_p↓（质子自旋轨道 35→15）溶解 Z=50，但 Sn 在 ε=0 仍比 Xe 深，峰位不移动；
  全量快速对比实证：λ_so=(35,35)→峰 A=104/132 峰高 43.9%，λ_so=(55,15)→峰不变、
  峰高崩到 15.6%（双峰被洗平）。
- γ 扫描存在结构矛盾：γ=1.1 是重碎片 N=82 合理选择但洗掉轻碎片形变闭合；γ=0.9
  轻碎片闭合出现但重碎片壳翻正。单一 γ 无法同时满足轻重碎片。
- **结论**：默认参数（λ_so=35、γ=1.1、p=4）是双峰最优，峰位偏 3 作为已知局限如实报告。
