# 数学物理公式说明（代码对应）

本文按模块逐条记录代码中用到的数学物理公式，给出物理意义、实现细节与代码位置。
记号约定：`q = (elong, neck, eta, eps1, eps2)` 为 3QS 五维形状参数；
A = Z + N 为质量数，I = (N−Z)/A 为同位旋不对称度；目标核素 U-236（Z=92, N=144）。

---

## 0. 总体框架：宏观-微观模型

```
E(q) = E_液滴(q) + δE_壳(q) + δE_对(q)
```

- `E_液滴`：FRLDM 有限力程液滴模型形变能（宏观，光滑，随形变单调）
- `δE_壳`：Strutinsky 壳修正（量子壳效应，产生非对称裂变与双峰势垒）
- `δE_对`：BCS 对修正（配对关联能，量级 −1~−2 MeV）

实现：[src/macro_micro.py](macro_micro.py) `MacroMicro.energy_components(q)`，返回
`(V_total, dV_s, dV_c, dE_sh, dE_pair)`。

## 1. 形状参数化：3QS 三二次曲面（src/shape.py）

核形状是**轴对称**的，用轮廓半径 ρ(z)（ρ = 到对称轴的垂直距离）描述。三段拼接：

```
                 ┌  a₁²·[1 − (z−l₁)²/c₁²]         (z < z₁)   左球体
ρ²(z) =  ⎨  ρ_v² + C·(z−z_v)²            (z₁ ≤ z < z₂)  中间二次曲面(颈)
                 └  a₂²·[1 − (z−l₂)²/c₂²]         (z ≥ z₂)   右球体
```

三段在 z₁、z₂ 处**切线相接**（位置与斜率连续），由判别式法解出。

### 1.1 参数 → 几何量

Nilsson 四极形变 ε 与轴比的关系（`axis_ratio`）：

```
a/c = (3 − 2ε) / (3 + ε)          (r₁ = axis_ratio(eps1), r₂ = axis_ratio(eps2))
```

两碎片体积占比（由质量不对称 η 决定）：

```
w₁ = (1 − η)/2        w₂ = (1 + η)/2          (轻碎片 w₁，重碎片 w₂)
```

椭球体积 4π/3·a²c = 4π/3·r²c³ 与碎片体积 w 相等，解出半轴：

```
c₁ = (w₁ / r₁²)^{1/3}     a₁ = r₁·c₁
c₂ = (w₂ / r₂²)^{1/3}     a₂ = r₂·c₂
```

两碎片球心位置（`elong` = 球心间距，无量纲，单位 R0）：

```
l₁ = −elong/2        l₂ = +elong/2
```

颈部顶点半径（`neck` 的物理含义）：

```
ρ_v = neck · min(a₁, a₂)         (neck ∈ (0,1]，neck=1 球、neck→0 断裂)
```

### 1.2 切线条件（判别式法）

中间二次曲面 ρ² = ρ_v² + C(z−z_v)² 须与两球体相切。将两式联立消去 z，切点重根条件
即判别式 Δ = 0：

```
Δ₁(B₁² − 4A₁C₁) = 0     Δ₂ = 0
A₁ = C + a₁²/c₁²,  B₁ = −2Cz_v − 2(a₁²/c₁²)l₁,  C₁ = ρ_v² + Cz_v² − a₁² + (a₁²/c₁²)l₁²
```

（A₂、B₂、C₂ 同理，下标换 2。）对称情形（η=0 且 ε₁=ε₂）有解析解：

```
w = D/2 − 2(a² − ρ_v²)c² / (a² D)          (D = elong)
C = a²·(D/2 − w) / (c²·w)
```

非对称情形用 `scipy.optimize.least_squares` 数值解上述 Δ₁=Δ₂=0（对称解作初值）。

### 1.3 体积守恒 + 质心居中（`_make`）

raw 形状体积 V = ∫ρ²dz（无量纲），质心 z̄ = ∫zρ²dz / V。做缩放 s 与平移：

```
s = (4/3 / V)^{1/3}          → 体积归一化到单位球 4/3
shift = −z̄·s                → 质心平移到 z=0
ρ²_final(z) = ρ²_raw((z−shift)/s) · s²
```

物理半径 = R0·√(ρ²)，R0 = r0·A^{1/3}（见 §2）。实现：[src/shape.py](shape.py)
`Shape3QS.build`（三段拼接）、`_make`（缩放居中）、`profile`（输出物理半径，单位 fm）。

## 2. 液滴模型：FRLDM（src/liquid_drop.py）

宏观形变能（相对球形，壳修正/对修正另加）：

```
ΔV(q) = E_S⁰·(B_s − 1) + E_C⁰·(B_c − 1)
```

其中 B_s、B_c 分别是形变形状相对球形的表面能比、库仑能比（球时 B_s=B_c=1，ΔV=0）。

表面能、库仑能的球形基准（`FRLDMPES.__init__`）：

```
E_S⁰ = a_s · (1 − κ_s·I²) · A^{2/3}              (表面能，a_s=21.18466 MeV, κ_s=2.345)
E_C⁰ = (3/5) · Z² · e² / R0                      (库仑能，e²=1.44 MeV·fm)
R0   = r0 · A^{1/3}                              (r0=1.16 fm)
```

### 2.1 表面能比 B_s（有限力程，Krappe–Nix–Sierk）

```
B_s = I_s(q) / I_s(球)
I_s = ∬ dσ · dσ' · Φ(|r⃗ − r⃗'|)
```

**有限力程核函数**（这是 FRLDM 区别于尖锐表面模型的核心）：

```
Φ(s) = [2 − (2 + s/a) e^{−s/a}] / s⁴         (s = 两表面点间距, a = 无量纲力程)
```

`dσ` 为表面法向面元向量，`∬` 对两表面点二重积分。轴对称下方位角 Δ 单独立出，代码
（`_surface_I`）中两个法向点积因子：

```
dot1 = ρ − ρ'·cosΔ − (z−z')·ρ'_z
dot2 = ρ·cosΔ − ρ' − (z−z')·ρ_z
```

对 (z, z', Δ) 做 Gauss–Legendre 积分。力程 a = a_range/R0，a_range=0.68 fm。
当 a→0 时 Φ(s) 退化为尖锐（几何）表面能。

### 2.2 库仑能比 B_c（尖表面，方位角解析）

```
B_c = I_c(q) / I_c(球)
I_c ∝ ∫∫ d³r d³r'  ρ_c(r) ρ_c(r') / |r⃗ − r⃗'|          (均匀带电体积分)
```

方位角积分解析完成（`_coulomb_I`），用到第一类完全椭圆积分 K：

```
∫₀^{2π} dφ / |r⃗ − r⃗'| = 4 K(m) / √(a+b)
a = (z−z')² + ρ² + ρ'²,   b = 2ρρ',   m = 2b/(a+b)
```

实现：[src/liquid_drop.py](liquid_drop.py) `_surface_I`（有限力程表面）、`_coulomb_I`
（库仑）、`energy_components`（ΔV = 表面项 + 库仑项）。

## 3. 单粒子势：变形 Woods-Saxon（src/woods_saxon.py）

单粒子势（universal Woods-Saxon，Dudek et al. 1981）：

```
V(r) = V_cent(r) + V_so(r) + V_Coul(r)
```

### 3.1 中心势（Fermi 型，带同位旋不对称）

```
V_cent(r) = −V0·[1 ∓ κ·I] / (1 + e^{d(r)/a})
    中子:  V_n(r) = −V0(1 − κI) / (1 + e^{d/a})
    质子:  V_p(r) = −V0(1 + κI) / (1 + e^{d/a}) + V_Coul(r)
```

- `d(r)`：到 3QS 表面的**带符号距离**（核内负、外正），由点到表面多段线最近距离求（`_signed_distance`）
- 符号判定：ρ_p < ρ(z_p)（核内）取负，否则取正

### 3.2 自旋轨道势

```
V_so = −λ(ħ/2mc)² (∇V_cent × p⃗)·σ⃗
```

令 S = λ(ħ/2mc)²（代码 `S = lam_so·(HBARC/(2M_NUC))²`）。

**球对称情形**（精确解基准，`spherical_single_particle_levels`）：

```
V_so(r) = −S · (1/r)(dV_cent/dr) · L⃗·σ⃗
        = −S · (dV_cent/dr)/r · [j(j+1) − l(l+1) − 3/4]
```

**变形（轴向）情形**，分解为对角项 + 耦合项（`_solve_block`）：

```
对角项(∝ ΛΣ):   V_so^diag = −S · (1/ρ)(∂V_cent/∂ρ) · 2ΛΣ
              Σ=+1/2 → −SΛ(1/ρ)∂V/∂ρ，Σ=−1/2 → +SΛ(1/ρ)∂V/∂ρ
耦合项(Λ↔Λ+1):   ⟨a|V_so|b⟩ = S·[Λ_b⟨V_z/ρ⟩ + ⟨V_z(∂_ρR_b)R_a⟩ − ⟨V_ρ(∂_zZ_b)Z_a⟩]
```

其中 Ω = Λ + Σ 是好量子数，Λ 为轨道角动量 z 分量、Σ = ±1/2 为自旋 z 分量。

### 3.3 质子库仑势（均匀带电球近似）

```
             ┌ (Z−1)e²·(3 − (r/R_c)²)/(2R_c)     (r ≤ R_c)
V_Coul(r) = ⎨
             └ (Z−1)e² / r                       (r > R_c)
```

### 3.4 基与对角化

轴对称**球谐谐振子基**，好量子数 (Ω, π)，宇称 π = (−1)^{n_z+Λ}：

- 谐振子频率 `ħω0 = 41/A^{1/3}` MeV，长度参数 `b = √(ħ²/(m·ħω0))` fm
- 基截断 `N_max = 12`，N = n_z + 2n_ρ + Λ ≤ N_max
- 按 (Ω, π) 分块，`numpy.linalg.eigh` 对角化
- 每个单粒子能级因时间反演（Kramers）**2 重简并**（后续配对/壳修正按 g=2 处理）

物理常数（`woods_saxon.py` 顶部）：ħc=197.327 MeV·fm、m_nuc=938.918 MeV、
e²=1.44 MeV·fm、ħ²/2m=20.73 MeV·fm²。

参数（`WS_DEFAULTS`）：V0=49.6 MeV、κ=0.86、r0=1.275 fm、a=0.70 fm、
λ_so=35、r0_coul=1.16 fm。

实现：[src/woods_saxon.py](woods_saxon.py) `_potential_fields`（势场）、`_solve_block`
（分块对角化）、`single_particle_spectrum`（返回质子/中子能级）。

## 4. Strutinsky 壳修正（src/strutinsky.py）

### 4.1 平滑核（曲率修正高斯，Laguerre 多项式）

```
f_p(x) = (1/√π) · e^{−x²} · L_p^{1/2}(x²)          (p = 6，曲率修正阶数)
```

L_p^{1/2} 为广义 Laguerre 多项式（`scipy.special.eval_genlaguerre(p, 0.5, x²)`）。

### 4.2 平滑能级密度与壳修正

```
g̃(ε) = Σ_i (g_i/γ) · f_p((ε−ε_i)/γ)              (g_i = 2，Kramers 简并)
δE_壳 = 2·Σ_{i=1}^{N/2} ε_i − ∫^{λ̃}_{−∞} ε·g̃(ε) dε
```

- 前一项是**占据能之和**（前 N/2 个轨道，每个占 2 核子）
- 后一项是**平滑占据能**（对平滑密度积分）
- 平滑费米能 λ̃ 由粒子数守恒定出：

```
N = ∫^{λ̃}_{−∞} g̃(ε) dε
```

平滑宽度 γ = γ₀·ħω0（MacroMicro 默认 γ₀ = 0.9；平滑网格步长 Δε = γ/20）。
壳修正为负表示该形状比平滑（均匀）单粒子谱更束缚 → 该形变是"幻数稳定"的。

实现：[src/strutinsky.py](strutinsky.py) `smoothing_kernel`、`shell_correction`。

## 5. BCS 对修正（src/pairing.py）

在费米面 ±window MeV 窗口内解 BCS 能隙方程。

### 5.1 能隙方程与占据

```
E_i = √[(e_i − λ)² + Δ²]                            (准粒子能量)
v_i² = (1/2)·(1 − (e_i − λ)/E_i)                    (占据概率)
Δ   = (G/2)·Σ_i Δ/E_i                               (能隙方程)
N   = 2·Σ_i v_i²                                     (窗口内粒子数)
```

化学势 λ 由粒子数守恒迭代修正，dN/dλ = Σ Δ²/E³：

```
λ ← λ + (N_window − N_calc) / (2·Σ Δ²/E³)
```

### 5.2 对修正能量

```
δE_对 = 2·Σ_i e_i·(v_i² − v_{i0}²) − Δ²/G
```

其中 v_{i0}² 是正常态（无配对）占据：`v_{i0}² = 1（e_i ≤ λ_F）或 0`。配对强度：

```
G = g0/A          (MacroMicro 默认 g0_n = g0_p = 16 MeV)
```

窗口外深束缚的核芯是惰性的（始终满占据），只守恒窗口内粒子数
`n_window = N − 2·idx[0]`。实现：[src/pairing.py](pairing.py) `bcs_solve`、
`pairing_correction`。

## 6. 宏观-微观整合（src/macro_micro.py）

```
V_total(q) = V_液滴(q) + δE_壳(q) + δE_对(q)
           = [E_S⁰(B_s−1) + E_C⁰(B_c−1)] + [δE_壳^n + δE_壳^p] + [δE_对^n + δE_对^p]
```

## 7. Metropolis 随机行走与路径（src/metropolis.py）

### 7.1 Metropolis 接受准则

```
P(q → q') = min(1, exp(−ΔV/T))          (T = 核激发温度, MeV)
```

无效形状（`build` 抛异常，如深颈 + 小拉长）直接拒绝。可做退火（T → T_end）与**棘轮**
（越过主势垒后 `elong` 只增不减，模拟裂变不可逆）。

### 7.2 断裂程度 f（`neck_fraction`）

```
f = 1 − ρ_颈 / ρ_最大 ∈ [0,1]
```

ρ_颈 = 内部局部极小半径（"腰"），ρ_最大 = 轮廓最大半径。f=0 无腰（球/光滑椭球）、
f→1 颈部断开。

### 7.3 极小能量（绝热）路径

每个 elong 下对 neck 取极小（η=ε₁=ε₂=0）：

```
V_min(elong) = min_{neck} V(elong, neck, 0, 0, 0)
```

实现：[src/metropolis.py](metropolis.py) `metropolis_walk`、`neck_fraction`、
`min_energy_path`、`compute_surface_slice`。
