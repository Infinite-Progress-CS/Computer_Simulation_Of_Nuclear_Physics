# 研究总览 · 文献基石 · 路线图

> 本文档是「重核裂变最优路径预测」项目的研究总览：梳理已完成的物理、涉及的经典基石论文、
> 计算裂变碎片产额所需的公式与模型，以及下一步路线。目标核素 **U-236**（Z=92, N=144）。

## 一、项目概览

在**五维核形变势能面**上做 **Metropolis 随机行走**，找重核裂变的极小能量（绝热）裂变路径，
最终目标是从「找最优路径」推进到「**预测实验可观测的裂变碎片产额分布**」。

物理框架是**宏观-微观模型**：

```
E(q) = E_液滴(q) + δE_壳(q) + δE_对(q)
```

- `E_液滴`：FRLDM 有限力程液滴模型（表面 + 库仑）
- `δE_壳`：Strutinsky 壳修正（单粒子能级来自变形 Woods-Saxon 势）
- `δE_对`：BCS 对修正

## 二、已完成的工作

1. 宏观-微观模型模块化实现（`src/` 下 9 个模块）。
2. 二维对称路径验证：幻数壳隙核对、球壳修正符号（mid-shell 正 ~+20 MeV）、
   对称路径势垒从纯液滴 12.66 MeV 压到 ~5.9 MeV 双峰。
3. 非对称裂变检查：固定 elong 扫 η，非对称（η≈0.19）能量低于对称（η=0）。
4. 五维随机行走 + 3D 分屏动画（对称 / 非对称）。
5. 裂变碎片产额分布示意 + 说明文档（`docs/产额分布说明.md`）。

## 四、计算裂变碎片产额：数学物理公式

### 已有（`src/` 里）

| 环节 | 公式 |
|------|------|
| 液滴能 | `ΔV = E_S0[B_s − 1] + E_C0[B_c − 1]` |
| 壳修正 | `δE_shell = Σ_occ ε_i − ∫^{λ̃} ε g̃(ε) dε`，`g̃ = (1/γ)Σ f_p((ε−ε_i)/γ)` |
| 对修正 | `1/G = Σ 1/√((ε_i−λ)²+Δ²)`，`δE_pair = −Δ²/G` |
| 随机行走 | `p(q→q') = min(1, e^{−ΔV/T})` |

### 新增（3 个，都很简单）

```
① 碎片间库仑能：   E_Coul = e² Z_L Z_H / d
② 断裂点产额：     Y(A_L,Z_L) ∝ exp[ −V_scission(A_L,Z_L) / T ]
   V_scission = [E_LD + δE_shell + δE_pair]_L + [同]_H + E_Coul
③ 核温度：         T = √(E*/a),  a ≈ A/8 MeV⁻¹
```

## 五、需要学习的模型

1. **断裂点模型（scission-point model）** —— 核心，唯一的新概念。
   Wilkins-Steinberg-Chasman (1976)：碎片分布由断裂瞬间势能决定，服从 `exp(−V/T)`。
2. **费米气体能级密度 / 核温度** —— 很轻，Bethe 公式。
3. **碎片壳修正随形变的变化 `δE_shell(β)`** —— 其实已会（`eps1/eps2` 就是碎片形变）。
4. **（可选）FRDM2012 / Möller 1995 质量表** —— 查碎片壳修正，避免对 ~200 个核现算。
5. **（进阶）布朗形变 / Langevin 动力学** —— Randrup-Möller，把随机行走升级成统计系综。

## 六、下一步路线图

```
第 0 步  抓实验数据：ENDF/B-VIII 的 U-235(n_th,f) 累计质量链产额 Y(A)
第 1 步  实现断裂点模型：复用 FRLDM + Strutinsky，算「两个碎片」的断裂点能量
第 2 步  算理论 Y(A)，与 ENDF 实测叠图对照（判据：双峰 ~95/~139、谷深 ~1/600）
第 3 步  随机行走升级成动态产额：固定 T 跑系综，断裂点记录 η → 直方图
```
