# 裂变碎片产额分布说明

## 1. 什么是产额分布

重核裂变后，两个碎片不是按固定比例分裂的，而是按**质量数 A**（以及电荷 Z）有一个分布。
实验测得的碎片质量产额曲线 `Y(A)` 就是「裂变碎片产额分布」。它是一组核反应中，
不同质量碎片出现频率（百分比）随 A 的变化，是裂变实验最直接、最经典的观测量之一。

## 2. 实验特征（U-235 热中子裂变 → U-236）

U-236 的碎片质量产额分布呈**双峰不对称**结构，核心特征如下：

| 特征 | 数值 |
|------|------|
| 轻碎片峰 | A ≈ **95** |
| 重碎片峰 | A ≈ **139** |
| 对称谷（均分 A=118） | 产额比峰低约 **500~600 倍**（对称裂变被强烈抑制） |
| 每个峰半高宽 FWHM | ~14~16 个质量单位 |
| 平均瞬发中子数 ν̄ | ≈ 2.4（95 + 139 + ~2 个中子 ≈ 236） |
| 精细结构 | 在幻数（N=82、Z=50）附近产额有局部尖峰/凹陷 |

## 4. 物理起源：壳效应

1. **纯液滴模型**只预言**对称裂变**（均分，η=0）：液滴表面能对均分最低，无法解释
   实验的双峰不对称——这也是纯液滴模型的三大失败之一（另两个是势垒偏高、轨迹直线）。
2. **壳修正**改变结局：碎片若靠近**幻数**，单粒子壳层能量更低（更束缚），总能量更低。
   - 重碎片峰 A≈139 落在 **N=82**（Sn-132 双幻数区，Z≈50）附近；
   - 轻碎片峰 A≈95 落在 **N=50** 附近。
   这两处的碎片最「稳」，故产额最高。
3. 中间的对称谷 A≈118（Z≈46、N≈72，**不在幻数上**）壳层能量高出约 **20 MeV**，
   导致对称裂变被压低约 500~600 倍。

## 5. 与模拟结果的对应

宏观-微观模型（FRLDM 液滴 + Strutinsky 壳修正 + BCS 对修正）沿 η 方向取能量极小，
最稳点出现在：

```
η = (M_H − M_L) / (M_H + M_L) ≈ 0.19
→  M_H ≈ 139,  M_L ≈ 95
```

**η≈0.19 反推的碎片质量正好落在实验双峰（~139 / ~95）上。** 这说明壳修正捕捉的，
正是决定实验产额分布的那个壳效应——纯液滴给 η=0（对称）是错的，加壳修正后 η 移到
0.19 才与实验一致。

## 6. 小结

- 实验产额分布是**双峰不对称**：轻峰 ~95、重峰 ~139、对称谷 ~118（低 ~600 倍）。
- 不对称性由**壳效应**驱动：碎片靠近 N=82 / N=50 幻数更束缚。
- 纯液滴无法解释（只能均分）；宏观-微观模型的最稳点 η≈0.19 定量落在实验峰位上，
  成功复现非对称裂变。
