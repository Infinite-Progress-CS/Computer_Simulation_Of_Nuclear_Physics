# 裂变产额分布计算结果汇报

目标核素 **U-236**（Z=92, N=144）。在 3QS 五维形变势能面上做 **Brownian/Metropolis
随机行走**（Randrup–Möller 2011），在断裂点采样质量不对称 η，经 KDE 光滑与 UCD 电荷标度
得到质量产额 Y(A) 与电荷产额 Y(Z)。

> 基础模型（3QS 形状、FRLDM 液滴、单中心 Woods-Saxon、Strutinsky、BCS）

> Brownian 形状运动随机行走取代，现已废弃（相关文件保留但生产流程不再调用）。

## 1. 新增核心：双中心 Woods-Saxon 基（TCSM）

`src/two_center.py` → `TwoCenterWoodsSaxon`。

**动机**：单中心谐振子基在鞍点/断裂区解不开双中心结构，非对称壳偏好被低估约 8.5 倍、
产额谷太浅。改用围绕两个碎片中心的移位谐振子基后，非对称裂变得以完整复现。

**单粒子哈密顿量**：

H = T + V(r) + V_so(r) + V_Coul(r)

**中心势（Woods-Saxon 势阱）**：

V(r) = V₀·[1 ∓ κ(N−Z)/A] / (1 + e^(d(r)/a))

**自旋轨道势**：

V_so = −λ(ℏ/2mc)²·(∇V_cent × p)·σ

**双中心基函数（非正交）**：

纵向　ψ_n(z; z_c) = N_n·H_n((z−z_c)/b)·e^(−(z−z_c)²/2b²)，n = 0..N_max
横向　R_{nρΛ}(ρ)（Laguerre 基，两碎片共享 ρ 轴）
谐振子长度 b = √(ℏ²/mℏω₀)，ℏω₀ = 41/A^(1/3) MeV

**广义本征问题**：

S_ab = ⟨ψ_a|ψ_b⟩，H_ab = ⟨ψ_a|H|ψ_b⟩
H·C = S·C·E

**数值正则化（重叠矩阵 S 近奇异时）**：

S = U·s·Uᵀ　→　V = U_keep·s_keep^(−1/2)　→　对角化 Vᵀ·H·V

**各项含义与物理意义**：

- **H**：单粒子哈密顿量，描述单个核子在变形核平均场中的运动。
- **T**：动能项。
- **V(r)**：中心势，Woods-Saxon 型核平均场；分母 `1+e^(d(r)/a)` 是费米型空间分布。
- **V₀**：势阱深度 49.6 MeV，代表核子感受到的平均势场强度。
- **κ**：同位旋不对称系数 0.86，控制势场对中子/质子不对称 (N−Z)/A 的敏感度。
- **N、Z、A**：中子数、质子数、质量数（A=N+Z）。
- **d(r)**：空间点到 3QS 核表面的带符号距离，核内为负、核外为正，刻画核表面的弥散。
- **a**：表面弥散度 0.70 fm，越大核表面越“软”。
- **V_so**：自旋轨道势，源自核子自旋与轨道运动耦合。
- **λ**：自旋轨道强度 35。
- **ℏ/2mc**：自旋轨道耦合系数。
- **σ、p**：泡利自旋矩阵、动量算符。
- **ψ_n、H_n、N_n**：移位谐振子波函数、Hermite 多项式、归一化系数。
- **z_c**：碎片中心位置；两中心使基函数“围绕”左右两个碎片。
- **b**：谐振子长度，由谐振子频率 ℏω₀ 决定。
- **S_ab、H_ab**：重叠矩阵元、哈密顿矩阵元；基非正交，故重叠矩阵 S 不为单位阵。
- **C、E**：本征矢量与本征能量（即单粒子能级）。
- **U、s、V**：重叠矩阵 S 的本征矢量、本征值，以及正交化后的变换矩阵。

## 2. 新增：Brownian 形状运动随机行走产额（蒙特卡洛模拟 + 断裂点采样 + 统计）

`src/random_walk_yield.py` → `brownian_yield`（Randrup–Möller 2011 PRL 106,132503）。

这是核心的**蒙特卡洛（Monte Carlo）模拟**：对 5D 势能面做 N 次 Metropolis 随机行走，
每次行走用高斯随机步 + Metropolis 接受/拒绝；行走到断裂点时**采样**质量不对称 η；
对所有行走的 η 做**统计**（直方图，归一 200%）得到产额分布。

**Metropolis 接受概率**：

P(i→i′) = min[1, exp(−ΔV_biased/T)]

**局域温度（形状依赖）**：

T² = (E* − V_rel)/aA，aA = A/(8 MeV)

**四极偏置势（加速越障，不重加权）**：

V_bias = V₀·(Q₀/Q)²

**四极矩**：

Q₂₀ = 2π·∫(z²ρ² − ρ⁴/4) dz

**断裂点采样**：物理颈半径 c_neck ≤ c₀ = 2.5 fm 时冻结并采样 η。

**统计**：N 条行走的 η → 质量直方图 → 归一 200%。

**各项含义与物理意义**：

- **P(i→i′)**：从形状 i 到 i′ 的 Metropolis 接受概率，保证平衡分布服从玻尔兹曼因子。
- **ΔV_biased**：加偏置势后的能量差 V(i′)−V(i)。
- **T**：局域核温度；越靠近基态（V_rel 小）温度越高，越接近激发能时温度越低。
- **E\***：复合核激发能 6.54 MeV（U-236 热中子诱发裂变）。
- **V_rel**：当前形状相对基态的势能。
- **aA**：费米气体能级密度参数，aA = A/(8 MeV)。
- **V_bias**：四极偏置势；对紧凑形状（Q 小）施加推力，帮助翻越裂变势垒，但不改变产额分布（不重加权）。
- **V₀**：偏置强度 25。
- **Q、Q₀**：当前形状、基态形状的四极矩。
- **Q₂₀**：轴对称形状的四极矩定义，prolate（长椭球）为正。
- **c_neck、c₀**：物理颈半径、断裂判据颈半径 2.5 fm。
- **η**：质量不对称 (M_H−M_L)/(M_H+M_L)，断裂时冻结。

## 3. 新增修正：颈参数化（η 解耦）

`src/shape.py`：

ρ_v = neck·a_ref，a_ref = (1/2)^(1/3) ≈ 0.794

**各项含义与物理意义**：

- **ρ_v**：颈部（中间二次曲面）顶点半径。
- **neck**：无量纲颈坐标 ∈(0,1]；neck=1 表示颈半径等于对称碎片半径，neck→0 表示断裂。
- **a_ref**：对称球形碎片的横向半轴 (1/2)^(1/3)，是固定常数、与 η 无关。

原来写成 ρ_v = neck·min(a₁,a₂)，会把“η 增大 → min(a₁,a₂) 变小 → 颈被错误变细”耦合，
制造假深非对称极小（液滴能量随 η 塌 ~9 MeV），并让大 η 形状在厚颈区无解。修正后颈半径只由
neck 坐标决定，与质量不对称 η 解耦。

## 4. 新增修正：KNS 有限力程表面核函数

`src/liquid_drop.py`：

B_s = (1/I_S^sph)·∮∮ Φ(s)·(n₁·r₁₂)(n₂·r₂₁)·dσ₁·dσ₂

Φ(s) = [2 − (x² + 2x + 2)·e^(−x)] / s⁴，x = s/a

**各项含义与物理意义**：

- **B_s**：形变形状相对球的表面能比（球时 B_s=1）。
- **I_S^sph**：球形参考表面积分（分母，用于归一化）。
- **Φ(s)**：有限力程 Yukawa-plus-exponential 核函数，刻画两个表面点之间的有限力程相互作用。
- **s**：两表面点之间的空间距离。
- **n₁、n₂**：两个表面点的外法向。
- **r₁₂、r₂₁**：两表面点连线方向的单位矢量。
- **dσ₁、dσ₂**：两个面元。
- **a**：有限力程 0.68 fm，核力程的量度。
- **x**：无量纲力程 s/a。

正确核必须含 x² 项；漏掉 x² 项会让有限力程修正弱 ~100 倍、势垒虚高 ~2 倍。

## 5. 新增修正：Strutinsky 壳修正（能级求和法）

`src/strutinsky.py`。壳修正改用「能级求和法」直接对能级求和，避免两个 ~2000 MeV 大数
相减导致的数值漂移。

**平滑核（曲率修正高斯）**：

f_p(x) = (1/√π)·e^(−x²)·L_p^(1/2)(x²)

**平滑能级密度**：

g̃(ε) = (1/γ)·Σ_i g_i·f_p((ε − ε_i)/γ)，g_i = 2

**壳修正能量**：

δE_sh = 2·Σ_{i=1}^{N/2} ε_i − 2·Σ_i ε_i·F_p((λ̃−ε_i)/γ) − 2γ·Σ_i G_p((λ̃−ε_i)/γ)

**粒子数守恒**（定平滑费米能 λ̃）：

N = 2·Σ_i F_p((λ̃−ε_i)/γ)

**各项含义与物理意义**：

- **f_p(x)**：曲率修正高斯平滑核，用于抹平单粒子能级的涨落。
- **L_p^(1/2)**：广义 Laguerre 多项式，p 为曲率修正阶数（取 p=4）。
- **γ**：平滑宽度（取 γ=1.1 ℏω₀），决定平滑尺度。
- **ε_i、g_i**：单粒子能级、能级简并度（g_i=2，时间反演简并）。
- **g̃(ε)**：平滑能级密度。
- **δE_sh**：壳修正能量，是占据能之和与平滑能之和的差。
- **F_p**：平滑占据数（f_p 的累积分布函数）。
- **G_p**：能量定理修正项（Brack & Pauli），缺少它壳修正会随 γ 漂移、无平台。
- **λ̃**：平滑费米能，由粒子数守恒确定。

## 7. 新增：产额提取（KDE + UCD + 电荷极化）

`scripts/plot_yield_final.py`。

**质量产额**：

A_L = A_parent·(1 − |η|)/2，A_H = A_parent − A_L

Y(A) ∝ p_A(A) + p_A(A_parent − A)（KDE 光滑，归一 200%）

**电荷中心（UCD + 电荷极化）**：

Z_p(A) = A·Z₀/A₀ + ΔZ(A)

ΔZ(A) = 轻碎片 +3 → 重碎片 +1（线性插值，截断 [0,4]）

**高斯电荷弥散**：

Y(Z) = Σ_A Y(A)·e^(−(Z − Z_p(A))²/2σ_z²)，σ_z = 0.5

**各项含义与物理意义**：

- **A_L、A_H**：轻、重碎片质量数，由 η 直接换算。
- **A_parent**：母核质量数 236。
- **p_A**：A_L 样本的核密度（KDE），即断裂时轻碎片质量数的概率密度。
- **Y(A)**：质量产额，按“轻碎片 + 重碎片”镜像相加，归一 200%（每裂变两个碎片）。
- **Z_p(A)**：质量 A 对应的最概然电荷数。
- **Z₀/A₀**：母核的质子占比 92/236（UCD：不等电荷分裂假定下的标度）。
- **ΔZ(A)**：电荷极化偏移，轻碎片偏 +3、重碎片偏 +1，反映碎片电荷极化。
- **σ_z**：电荷弥散宽度 0.5。
- **Y(Z)**：电荷产额，把每个 A 的产额按高斯弥散到相邻 Z。

## 8. 结果

U-236 热中子裂变，8000 走大统计（n_eta_sub=30，V0=25，8×1000 并行合并）：

| 量 | 计算值 | FRLDM 2020 | 实验 |
|------|--------|-----------|------|
| 质量峰 A | 96 / 140 | 100 / 136 | 95 / 134 |
| 电荷峰 Z | 41 / 55 | 39 / 53 | 40 / 56 |
| 峰谷比 P/V（质量） | 9 | 929 | ~200 |
| 断裂率 | 76%（6090/8000） | — | — |
| 非对称占比 | 98% | — | ~100% |

- 峰位对齐 Möller 基准（质量 A=96/140；电荷 Z=41/55 偏实验 ±1）；
- 非对称裂变完整复现（断裂点 η 双峰、轻碎片形变 ε₁ > 重碎片 ε₂）；
- 已知局限：产额谷偏浅（P/V≈9 vs 实验≈200），根因是分岔点（neck≈0.7）临界减速导致
  η 冻结（Kibble–Zurek），双中心基在分岔点的不对称偏好≈0、只在 neck≤0.6 才爆发。
