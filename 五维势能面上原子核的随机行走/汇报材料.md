# 汇报材料：基于双中心 Woods-Saxon 基的 U-236 裂变碎片产额分布

> **方法主线**：宏观-微观模型构建 5D 形变势能面 → Brownian 形状运动随机行走（Möller/Randrup 方法）→ 断裂点采样拟合 → 质量/电荷产额分布。

---

## 一、项目概述

- **目标**：复现 U-236（Z=92, N=144）热中子诱发裂变的碎片产额分布，对齐 Möller 基准（质量峰 A=96/140、电荷峰 Z=40/56）。
- **方法**：严格按 Möller/Randrup 的 Brownian 形状运动——在 5D 形变势能面上做 Metropolis 随机行走，断裂点（颈半径 ≤ 2.5 fm）冻结质量不对称 η，对 η 采样做 KDE 拟合得到产额。
- **核心难点与突破**：单中心谐振子基在鞍点/断裂区解不开双中心结构，导致非对称偏好被低估约 8.5 倍、谷浅。本项目实现**统一的双中心（移位谐振子）Woods-Saxon 基**取代人工插值，根治此问题。

---

## 二、理论框架：宏观-微观模型

总势能面为宏观液滴能与微观壳/对修正之和，对每个形变点 q 计算：

E(q) = E_液滴(q) + δE_壳(q) + δE_对(q)

其中单粒子能级由**变形（双中心）Woods-Saxon 势**解出，宏观部分用 **FRLDM 有限力程液滴模型**。5 个形变坐标：

q = (q₁, q₂, q₃, q₄, q₅) = (elong, neck, η, ε₁, ε₂)

## 三、核心数学模型与公式

### 3.1 5D 形状参数化：3QS 三二次曲面（`src/shape.py`）

轴对称形状剖面 ρ(z)（无量纲，物理半径 = R₀·ρ，R₀ = r₀A^(1/3) ≈ 7.17 fm）。

**Nilsson 四极形变 → 椭球半轴**（体积守恒 a²c = 1）：

r = a/c = (3−2ε)/(3+ε)，a = r^(1/3)，c = r^(−2/3)

**质量不对称与碎片权重**：

η = (M_H − M_L)/(M_H + M_L)，w₁ = (1−η)/2，w₂ = (1+η)/2

左右碎片椭球半轴由各自质量权重与形变决定：

c_i = (w_i/r_i²)^(1/3)，a_i = r_i·c_i，r_i = (3−2ε_i)/(3+ε_i)，i = 1,2

**颈参数化**（颈半径与质量不对称 η 解耦）：

ρ_v = neck·a_ref，a_ref = (1/2)^(1/3) ≈ 0.794（对称球形碎片的横向半轴）

> 注意：不能写成 ρ_v = neck·min(a₁,a₂)——那样 η 增大会把颈错误变细、与颈部收缩耦合，
> 制造假深非对称极小，并让大 η 形状在厚颈区无解。

**三段二次曲面**（左球 + 中间二次曲面 + 右球，切线拼接）：

ρ²(z) = a₁²·[1 − (z−l₁)²/c₁²]（z < z₁）；
ρ_v² + C·(z−z_v)²（z₁ ≤ z ≤ z₂）；
a₂²·[1 − (z−l₂)²/c₂²]（z > z₂）

其中 l₁ = −elong/2, l₂ = +elong/2 为两碎片中心位置。中间曲面与两球相切条件（判别式为零）唯一确定 z_v, C, z₁, z₂。对称情形（η=0, ε₁=ε₂）有解析解：

D_min = 2c·√(1 − ρ_v²/a²)，w = D/2 − 2(a² − ρ_v²)c²/(a²D)，C = a²(D/2 − w)/(c²w)

非对称情形用 `least_squares` 数值解判别式方程（对称解作初值）。

**物理量定义**：

| 参数 | 符号 | 物理含义 |
|---|---|---|
| q₁ | elong | 拉长 = 两碎片中心间距 / R₀ |
| q₂ | neck | 颈部 = 中间顶点半径 ρ_v / a_ref ∈ (0,1]，a_ref = (1/2)^(1/3) |
| q₃ | η | 质量不对称 = (M_H−M_L)/(M_H+M_L) |
| q₄ | ε₁ | 轻碎片 Nilsson 四极形变 |
| q₅ | ε₂ | 重碎片 Nilsson 四极形变 |

### 3.2 宏观能：有限力程液滴模型 FRLDM（`src/liquid_drop.py`）

ΔV(q) = E_S⁰·[B_s(q) − 1] + E_C⁰·[B_c(q) − 1]

表面与库仑能球面基准（I = (N−Z)/A）：

E_S⁰ = a_s·(1 − κ_s·I²)·A^(2/3)，E_C⁰ = (3/5)·Z²e²/R₀

参数（FRLDM 1995, ADNDT 59,185）：a_s = 21.18466 MeV, κ_s = 2.345, r₀ = 1.16 fm, 力程 a = 0.68 fm。

**有限力程表面能**（Krappe–Nix–Sierk Yukawa-plus-exponential 双重曲面积分）：

B_s = (1/I_S^sph)·∮∮ Φ(s)·(n₁·r₁₂)(n₂·r₂₁) dσ₁ dσ₂

其中核函数（无量纲力程 x = s/a，s = 两表面点间距）：

Φ(s) = [2 − (x² + 2x + 2)·e^(−x)]/s⁴，x = s/a

**库仑能**（尖表面电荷，方位角解析积分化为完全椭圆积分 K）：

B_c = (1/I_C^sph)·∫ ρ(r₁)ρ(r₂)/|r₁ − r₂| d³r₁ d³r₂

方位角积分后（aa = (z₁−z₂)²+ρ₁²+ρ₂², b = 2ρ₁ρ₂, m = 2b/(aa+b)）：

I_C = 2π·∫∫∫∫ ρ₁ρ₂·4K(m)/√(aa+b) dz₁ dz₂ dρ₁ dρ₂

对数奇点（两体积元重合 m→1）用 **Richardson 外推**（n 与 2n/3 两套网格按 1/n² 外推）消除，误差压到 ~0.02 MeV。

### 3.3 微观单粒子势：变形 Woods-Saxon（`src/woods_saxon.py`）

单粒子势（universal Woods-Saxon, Dudek 1981）：

V(r) = V₀·[1 ∓ κ·(N−Z)/A]/(1 + e^(d(r)/a)) + V_so(r) + V_Coul(r)

- d(r) = 到 3QS 表面的**带符号距离**（核内负、外正）
- 参数：V₀ = 49.6 MeV, κ = 0.86, r₀ = 1.275 fm, 弥散度 a = 0.70 fm

**自旋-轨道耦合项**：

V_so = −λ·(ℏ/2m_N c)²·(∇V_cent × p)·σ

定义自旋轨道强度 S = λ(ħ/2m_N c)²（λ_so = 35，约 0.81 fm²·MeV⁻¹ 量级）。按 Ω = Λ+Σ 分块后，对角项（Λ 守恒）：

V_so^diag = −S·(1/ρ)·(∂V_cent/∂ρ)·2ΛΣ　⇒　Σ = +1/2：−SΛ，Σ = −1/2：+SΛ

耦合项（l_∓ σ_±，连接两条 Λ 分支，Λ_b = Λ_a+1）：

⟨a|V_so|b⟩ = S·[Λ_b·⟨V_z/ρ⟩ + ⟨V_z·(∂_ρ R_b)·R_a⟩ − ⟨V_ρ·(∂_z Z_b)·Z_a⟩]

**质子库仑**（均匀带电球近似，R_c = r₀_coul·A^(1/3)）：

V_Coul(r) = (Z−1)e²/(2R_c)·[3 − (r/R_c)²]（r ≤ R_c）；(Z−1)e²/r（r > R_c）

### 3.4 双中心 Woods-Saxon 基（**新增核心**，`src/two_center.py`）

单粒子势仍是完整双中心 WS 势（由 shape 的有符号距离给出，**无需改 shape**），但基函数换成**围绕两个碎片中心 ±z_c 的移位谐振子**（非正交），即标准两中心壳模型（TCSM）。

- **横向（ρ）**：Laguerre 基 R_{nρΛ}(ρ)（两碎片共享 ρ 轴，与单中心相同）
- **纵向（z）**：移位 Hermite {ψ_n((z−z_L)/b), ψ_n((z−z_R)/b)}，n = 0…Nmax_z
- 谐振子长度 b = √(ℏ²/m_N ℏω₀)，ℏω₀ = 41/A^(1/3) MeV

**两中心位置自动检测**（`detect_centers`）：由剖面 ρ(z) 找颈最深极小 → 分左右两瓣 → 取瓣峰（ρ 最大处）作为 z_L、z_R。颈未充分收缩（ρ_neck/ρ_lobe > 0.6）时返回 None，回退单中心基。

**按 Ω = Λ+Σ 分块**（η≠0 时形状无反射对称，宇称不再是好量子数）。每 Ω 块含两条 Λ 分支：Λ_a = Ω−½（Σ=+½）与 Λ_b = Ω+½（Σ=−½），求解**广义本征问题**：

H·C = S·C·E　⇒　eigsh(VᵀHV)，V = U_keep·s_keep^(−1/2)

数值稳定化：对重叠矩阵 S = U s Uᵀ 做本征分解，截断近零本征值（s > ε = 10⁻²），再用 V = U_keep·s_keep^(−1/2) 正交化转回标准本征问题，避免 10⁵–10⁷ MeV 的假本征值。

**z₀→0 极限**：|z_R − z_L| < z₀_min·b 时两中心重合、基近线性相关，自动回退单中心 `WoodsSaxon`，保证球/紧凑形状正确。

### 3.5 Strutinsky 壳修正（`src/strutinsky.py`）

平滑核（曲率修正高斯，p 阶广义 Laguerre 多项式）：

f_p(x) = (1/√π)·e^(−x²)·L_p^(1/2)(x²)

壳修正 = 占据能之和 − 平滑能之和（能级求和法，数值稳定）：

δE_壳 = 2·Σ_{i=1}^{N/2} ε_i − 2·Σ_i ε_i·F_p((λ̃ − ε_i)/γ) − 2γ·Σ_i G_p((λ̃ − ε_i)/γ)

其中 F_p 为 f_p 的累积分布，平滑费米能 λ̃ 由粒子数守恒确定：

N = 2·Σ_i F_p((λ̃ − ε_i)/γ)

G_p(v) = ∫ᵛ₋∞ x f_p(x) dx 为「能量定理」修正项（Brack & Pauli 1973），缺此项则壳修正随 γ 单调漂移、无平台。取 p = 4、平滑宽度 γ = 1.1 ħω₀。

### 3.6 BCS 对修正（`src/pairing.py`）

在费米面 ±window 窗口内解 BCS 能隙方程：

Δ = (G/2)·Σ_i Δ/E_i，E_i = √((e_i − λ)² + Δ²)

占据概率与化学势：

v_i² = (1/2)·(1 − (e_i − λ)/E_i)，N = 2·Σ_i v_i²

对修正能量（相对正常态）：

δE_对 = 2·Σ_i e_i·(v_i² − v_{i0}²) − Δ²/G，G = g₀/A（g₀ = 16）

### 3.7 宏观-微观总能量（`src/macro_micro.py`）

E(q) = [E_S⁰(B_s−1) + E_C⁰(B_c−1)]（FRLDM 液滴）
　　+ [δE_壳ⁿ + δE_壳ᵖ]（Strutinsky）+ [δE_对ⁿ + δE_对ᵖ]（BCS）

中子/质子壳修正与对修正分别对各自单粒子能级求和。基态能量基准 V_gs 由紧致区粗扫求得。

## 四、Brownian 形状运动与产额提取（`src/random_walk_yield.py`）

强阻尼（Smoluchowski）极限下，核形状演化等价于 5D 势能面上的随机行走。

### 4.1 Metropolis 判据

高斯随机步 + 边界裁剪，接受概率：

P(i→i′) = min[1, exp(−ΔV_biased/T)]

### 4.2 偏置势与局域温度

**偏置势**（加速越障，不重加权，Q 为四极矩）：

V_bias = V₀·(Q₀/Q)²，Q₂₀ = 2π·∫(z²ρ² − ρ⁴/4) dz

**形状依赖局域温度**（Randrup–Möller 2011，V_rel 相对基态）：

T² = (E* − V_rel(q))/(aA)，aA = A/(8 MeV)

### 4.3 断裂判据与质量产额

颈半径 ≤ c₀ = 2.5 fm 时冻结质量不对称 η，提取碎片质量：

A_L = A_parent·(1 − |η|)/2，A_H = A_parent − A_L

质量产额 Y(A) ∝ 行走到断裂点的次数（归一 200%，每裂变两碎片）。

### 4.4 质量产额 → 电荷产额（`scripts/plot_yield_final.py`）

**光滑**：对 η_scission 样本做核密度估计（Gaussian KDE），消除有限行走直方图的尖刺：

Y(A) ∝ p_A(A) + p_A(A_parent − A)，A_L = A_parent·(1 − |η|)/2

**UCD 标度 + 电荷极化 + 高斯弥散**：

Z_p(A) = A·Z₀/A₀ + ΔZ(A)，ΔZ(A) = dz_light + (dz_heavy − dz_light)/(A_heavy − A_light)·(A − A_light)

Y(Z) = Σ_A Y(A)·e^(−(Z − Z_p(A))²/2σ_z²) / Σ_Z′ e^(−(Z′ − Z_p(A))²/2σ_z²)

经验参数：dz_light = +3, dz_heavy = +1, σ_z = 0.5。

## 七、已知局限

1. **产额谷偏浅**（P/V ~ 1–2，实验 ~200–600）：这是 Brownian 形状运动的动力学冻结（Kibble-Zurek 临界减速）所致——η 在分岔点（neck≈0.7）冻结、跟不上移动极小。断裂点 PES 本身的非对称偏好是强的（13 MeV），问题在行走动力学，非壳修正。时间尺度分离（`n_eta_sub`，η 弛豫子步）可治本：对称占比随 n_eta_sub 单调降 10.6%(0) → 2.7%(5) → 1.4%(15)，代价是计算量线性增加。
2. **电荷峰偏 1**（Z=41/55 vs 实验 40/56）：经验极化参数可微调。
3. **势垒偏低**（2.62 vs Möller 5.03 MeV）：3QS 参数化液滴势垒偏低的已知特征。
