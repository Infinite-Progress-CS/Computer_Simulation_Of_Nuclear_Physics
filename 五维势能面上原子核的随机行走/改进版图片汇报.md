# 裂变碎片产额分布图改进版说明

**对象：U-236（Z=92, N=144）**

---

## 一、研究目标

在五维形变势能面上描述 U-236 的裂变过程，核心是复现实验观测到的**非对称裂变**特征，
即碎片质量/电荷产额的双峰分布（轻峰 ~Z=40、重峰 ~Z=56），并给出裂变最优路径。

## 二、物理模型

采用**宏观-微观模型**，把核形变势能写成三项：

```
E(q) = E_液滴(q) + δE_壳(q) + δE_对(q)
```

- **E_液滴**：有限力程液滴模型（FRLDM），表面能 + 库仑能；
- **δE_壳**：Strutinsky 壳修正，单粒子能级由变形 Woods-Saxon 势对角化得到；
- **δE_对**：BCS 对修正。

形状由 3QS 三二次曲面坐标描述，五个参数：
`(elong 拉长, neck 颈部, eta 质量不对称, eps1 左碎片形变, eps2 右碎片形变)`。

## 三、本轮新增内容（相比上次静态断裂点模型）

1. **双中心壳修正**：断裂区量子修正从「满核单中心」切换到「碎片级双中心」，
   从而复现非对称裂变——近断裂时碎片各自保留其壳结构（如重碎片的 N=82 幻数）。

2. **Brownian 形状运动产额**（Randrup–Möller 2011, PRL 106, 132503）：
   在势能面上做 Metropolis 随机行走，局域温度 T² = [E* − V(q)] / (A/8)，
   以颈半径 c_neck ≤ 2.5 fm 作为断裂判据，冻结质量不对称度 η。

3. **库仑 Richardson 外推**：修复库仑 4 重积分 ~1/n² 慢收敛问题。

4. **高斯电荷弥散**：由质量产额 Y(A) 卷积高斯得到电荷产额 Y(Z)（σ_Z = 0.75）。

5. **Strutinsky 奇偶交错修复**：部分占据替代银行家舍入，消除奇数核的壳修正锯齿。

## 四、核心结果（电荷产额分布）

有效温度 T = 4.5 MeV，断裂点模型电荷产额 Y(Z) 与实验 ²³⁵U(n,f) 对比：

| 位置 | 计算 Calc. | 实验 Exp. |
|------|-----------|----------|
| 轻峰 Z | 41（16.49%） | 40（17.10%） |
| 重峰 Z | 51（16.49%） | 56（14.89%） |
| 谷  Z | 46（2.31%） | 46（0.07%） |

- **成功复现**：非对称双峰结构、峰高量级（~16–17%）与实验对齐，轻峰位置（Z=41 vs 40）吻合良好。
- **待改进**：重峰位置偏 5（Z=51 vs 56），谷偏浅（2.31% vs 0.07%）。

## 五、已知局限与后续方向

重峰偏移的根因是 **Sn-132 双幻数（Z=50, N=82）在模型中被过强绑定**，导致重碎片被钉在
Z=51 附近，而实验重峰在 Z=56（Xe/Ba，仅 N=82）。这属于单一 Woods-Saxon 参数集 +
断裂点近似的结构性局限，后续可尝试：

- 调 Woods-Saxon 单粒子参数修正幻数位置（N=82 壳中心在 A≈138–140）；
- β₄ 十六极形变自由度；
- 中子蒸发卷积（累计产额 vs 独立产额口径）。
